# Portero

Mod para Claude que elige automáticamente el modelo más económico que alcance para cada pedido, para que el límite de uso dure más. Antes de cada mensaje, un modelo chico clasifica el pedido como simple (Haiku), medio (Sonnet) o complejo (Opus) y muestra un aviso con el modelo elegido. Para forzar un modelo, escribir #haiku, #sonnet u #opus en el mensaje.
